# Configuração principal

Edite estes arquivos pelo GitHub ou no Termux:

## `bots.json`

Coloque o token do BotFather e a chave Gemini do bot ativo.

## `groups.json`

Coloque somente os grupos/canais permitidos a receber sinais.

Se não souber o ID correto, adicione o bot ao grupo como administrador e envie no grupo:

```text
/id
```

O bot responde com o `chat_id`. Copie esse número para `groups.json`.

## `links.json`

Configura o botão `📌 REGISTRAR AGORA`.

## `settings.json`

Configura intervalos, API, quiz, logs e monitoramento de mensagens.
